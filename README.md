# CNC Toolkit

Suite d'add-ins pour Autodesk Fusion 360 destinée à la conception de meubles et d'agencements en bois découpés sur CNC : tenons, mortaises, jeux de fonctionnement, entailles à mi-bois, dogbones, gravure des pièces et calpinage, réunis dans une palette unique.

**Site et téléchargement :** https://maxnc62.github.io/cnc-toolkit/

## Installation rapide (Windows)

1. Télécharger `CNC_Toolkit_Installation.zip` depuis le dossier [`telecharger`](telecharger/CNC_Toolkit_Installation.zip) ou le site.
2. Extraire le zip, fermer Fusion 360, lancer `INSTALLER.bat`.
3. Dans Fusion : `Maj+S` > onglet Compléments > ToolkitCNC > cocher « Exécuter au démarrage » > Exécuter.

Le détail est dans `LISEZMOI.txt` inclus dans le zip.
